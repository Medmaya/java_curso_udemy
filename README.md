# ☕ Java - Curso Udemy

Este repositório foi criado para armazenar os exercícios e projetos desenvolvidos durante o curso de Java.

## 📚 Objetivo

Praticar os principais conceitos da linguagem Java, desde lógica de programação até Programação Orientada a Objetos (POO), aplicando os conhecimentos em exercícios e projetos.

## 📂 Conteúdo

- Introdução à Programação Orientada a Objetos
- Classes e Objetos
- Atributos
- Métodos
- Construtores
- Encapsulamento
- Herança
- Polimorfismo
- Tratamento de Exceções
- Coleções
- Projeto de Xadrez (em desenvolvimento)

## 🛠️ Tecnologias

- IntelliJ IDEA
- Git
- GitHub
